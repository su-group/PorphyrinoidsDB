# 按 Meso 取代基（B_number）留一外推的快速测试

> 目的：骨架划分已经把 Test R² 压到 0.28–0.37。用户问的是**另一条设计轴**——meso 取代基（B 编号）——是否也存在同样的外推失败。
> 结论先行：**没有。B 轴几乎是无损的（XGBoost R² 0.873–0.892，随机划分是 0.884–0.922），代价约 0.01–0.03；真正脆的是核心骨架。**
> 但"好"的原因不是模型学会了取代基化学，而是 B 本身对 gap 几乎没有独立贡献（见 §3）。
>
> 状态：§1–§7 为**探索性快速测试**（`.dsh_tmp\bsplit_test.py`、`bsplit_test2.py`、`bsplit_diagnostics.py`；明细 `.dsh_tmp\bsplit_results.csv`、`bsplit_results2.csv`、`bsplit_folds2.csv`），未改动任何实验目录。
> §8 起是**正式实验**：B 轴已接入固定划分体系与主流水线（`experiments\20261021_B-M`、`experiments\20261021_B-MF`），10 个模型 × 100 trial，与 R/S 四组同预算。

## 1. 协议

- 数据：全部 **1,734** 条有效记录（不是四组主实验里 1,383 那半），否则留出的 B 在训练集里没有可比分子。
- 划分：**leave-one-B-out**，16 个 B 各留出一次（每次 97–126 个测试分子，训练约 1,610）。
- 预处理：完全复用流水线的 `fit_preprocessing` / `transform_features`（折内中位数填充、方差与 |r|>0.95 剪枝、标准化），所以每折保留列数会随训练折变化。
- 参照系（同一批折上重算）：
  - **constant**：只用训练折均值；
  - **composition**：只用 A_number / X_element / C_number 的 one-hot 做 Ridge ——**故意不含 B**，因为留出的取代基无法生成哑变量；
  - **random 5-fold**：同一估计器、同一预处理，只是不按 B 分组。
- 模型：Ridge(α=10)（线性，代表会外推的那类）、Ridge 预测裁剪到训练折目标区间、XGBoost（树模型，结构上不外推）。

读法：

1. **B 轴外推几乎不花钱**：同协议下 XGBoost 从随机 0.884/0.922 掉到剔除 B0 的 0.873/0.892，只差 0.011/0.030。
2. **骨架轴要付 0.55 的 R²**（0.922 → 0.37），这才是真正的失效点。
3. **线性模型在 B 轴上会崩**：Mordred 特征下 Ridge MSE 5.12（R² −3.78），裁剪后仍有 2.97。这不是"没信号"，而是线性外推在共线特征上放大 z 分数——证据是同一批折上树模型只有 0.136。所以这条轴上能用的是树集成，不是核/线性方法。
4. **描述符确实比纯组成强 3.6 倍**（0.414 → 0.115，剔 B0），说明分子描述符本身携带了 A/X/C 哑变量表达不了的信息。

## 3. 为什么 B 轴上"容易"：B 本身几乎不承载 gap 方差

用 1,734 条数据做纯组均值模型的 in-sample R²（这是各因子能携带的方差上界）：

| 因子 | 组数 | R² |
|---|---|---|
| A_number（骨架） | 18 | **0.527** |
| B_number（meso 取代基） | 16 | **0.003** |
| X_element（核心杂原子） | 4 | 0.068 |
| C_number（配位态） | 3 | 0.007 |
| A + X + C | 134 | 0.943 |
| A + B | 258 | 0.548 |

- **B 单独只解释 0.3% 的方差**；在 A 之上再加 B，R² 从 0.527 只到 0.548。
- 固定一个核心（A, X, C）后，各 B 均值之间的标准差：**中位 0.136 eV、90 分位 0.379 eV**（114 个满足 ≥3 个 B 的核心）；而整体 gap 的 sd 是 **1.036 eV**。也就是说，换 meso 取代基只把 gap 挪动约 1/8 个标准差。
- 所以"留一 B 预测得好"主要说明：**gap 由核心决定，取代基是一阶小扰动**；模型只要认得核心，就能猜得不错。这不等于"模型学会了新取代基的化学"。
- 注意：`A+X+C+B` 的组均值 R² = 1.000，但那是 1,734 个组合对 1,734 行、每组一行，**退化，不能引用**。

## 4. 两个必须写明的陷阱

### 4.1 B0 这一折其实是骨架留出，不是取代基留出

`B_number = 0`（meso 位为 H）这一折包含 **A13 与 A14 的全部 20 个分子**，而 A13/A14 只以 B0 出现。留出 B0 等于同时留出两个骨架：

- XGBoost 在 B0 折上 MSE **4.53**（混合）／**2.85**（Mordred），而其余 15 折是 **0.028–0.277**；
- 这就是把 pooled 数字从 0.1155 抬到 0.4366 的唯一原因。

所以 B 轴结论必须写成"剔除 B0 的 15 折"，否则会把骨架效应误报成取代基效应。B0 本身（无芳基取代的 meso 位）也确实是化学上真正的外推，它给出的教训与骨架划分一致。

### 4.2 线性外推会爆，裁剪只能掩盖

Mordred 特征下 Ridge 在 B=2 折 MSE 58.57，裁剪到训练目标区间后仍是 24.89——说明预测值远远飞出区间，不是靠 clip 能修的。混合特征下同一折 Ridge 是 0.74、XGBoost 是 0.28。写进稿件时，任何"按 B 留一也尚可"的表述都必须注明估计器类型。

## 6. 结论

1. **B 轴（meso 取代基）不是失效轴**：树模型留一外推 R² 0.873（Mordred）/ 0.892（混合），与随机划分只差 0.01–0.03。
2. **失效轴是骨架**：0.92 → 0.37，损失 0.55；两条轴的量级完全不可比。
3. 原因不是模型学到了取代基化学，而是 **B 单独只解释 0.3% 的方差、组内只挪 0.14 eV**，gap 由核心主导——所以"按 B 留一容易"与"按骨架留一困难"其实是同一件事的两面。
4. 估计器选择在这里是决定性的：同一批折上线性模型 MSE 5.12、树模型 0.136。若要在稿件里写这条轴，必须说明估计器，并且把 B0 折单独标注为骨架外推。

## 7. 可选的后续（若要把这条轴写进稿件）

## 8. 正式实验（B-M / B-MF，与 R/S 四组同预算）

上面 §1–§7 是"留一 B"的探索口径。为了和主实验可比，这里把 B 轴做成了**真正的第五条/第六条实验**：固定划分清单 + 同一套流水线 + 10 个模型 × 100 trial Optuna + 5 折 CV。

### 8.1 划分清单

`experiments\20261021_splits_meso.json`（生成脚本 `.dsh_tmp\make_b_split.py`），沿用 R/S 清单的同一 schema（`data_sha256` / `samples` / `seed` / `folds`），主流水线通过 `--split-file ... --split-name meso` 读取。

| 项 | 值 |
|---|---|
| 分组 | `B_number`（16 个 meso 取代基） |
| 训练 / 测试 | 1,398 / 336（19.38%） |
| 测试组 | **B5 / B11 / B15**（112 + 111 + 113） |
| 五折（GroupKFold） | fold0 {B0,B6} n=230；fold1 {B2,B4,B14} n=319；fold2 {B3,B8,B12} n=314；fold3 {B1,B7} n=217；fold4 {B9,B10,B13} n=318 |

标签分布两边几乎一致（训练 mean 6.2836 / sd 1.0423；测试 mean 6.2661 / sd 1.0101），所以**下面 CV 与 Test 的差异不可能是"测试集标签更容易"造成的**。

### 8.3 CV 与 Test 为什么差这么多：折里留的是 B0

用同一套预处理（`core.train_optimizer.fit_preprocessing`）在训练集内做**留一 B 组**（每次只用其余 12 个组训练），再单独用全部 1,398 条训练、对 3 个测试组打分，脚本 `.dsh_tmp\bgroup_difficulty.py`：

结论有三点：

1. **B0（meso 位为 H，即无取代基的母体）是整条轴上唯一真正的"外推"组。** 树模型在 B0 上的 MSE 是 7.47，其余 12 个训练组是 0.12–0.42——差 20–60 倍。B0 全部落在 fold0，所以 fold0 一个折就顶起了整个 CV 均值：按样本量加权，fold0 ≈ (126×7.47 + 104×0.31)/230 ≈ **4.23**，其余四折 ≈ 0.34 / 0.15 / 0.15 / 0.17，五折平均 ≈ 1.0。这与流水线报出的 RF CV MSE 0.7400 同量级（差别来自我用了 `result.pkl` 里的最优参数重拟合，`n_estimators=14`）。
2. **测试组 5/11/15 恰好抽到了甜点。** 在 16 个组里，B5 排第 14–15 难、B15 排第 13–16 难，只有 B11 偏难（Lasso 第 1、RF 第 8）。所以 Test R² 0.87 不是"B 轴外推普遍很好"，而是"这次抽到的三组比较好"。
3. **B 轴的平均难度远低于骨架轴。** 留一 B 的平均 MSE：Lasso 0.4648、RF 0.7717（被 B0 拖高，剔除 B0 后中位 0.176）；同一批数据上按骨架留出的最好 Test R² 只有 0.28–0.37。

因此正确的表述是：**meso 轴整体是插值友好的（换一个取代基只挪动 gap 约 0.14 eV），但"去掉取代基回到母体"（B0）是货真价实的外推，与骨架外推同类；单次测试划分的 R² 取决于它抽到哪几个取代基，不能当作该轴的总体能力。**
